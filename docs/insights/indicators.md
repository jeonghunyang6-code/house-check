# 지표 구현 명세

[viewpoints.md](viewpoints.md)의 관점을 계산 가능한 지표로 옮긴 문서다.
각 지표에 정의, 계산식, 기준선, 데이터, 주기, 화면을 적는다.

**기준선 출처 표기**
- 📖 책에 숫자가 명시됨 → 그대로 사용
- ▶ 유튜브에 숫자가 명시됨 → 그대로 사용
- 🔧 작가는 방향만 말함 → 초기값을 두고 과거 데이터(2021 고점, 2023 초 저점)로 **백테스트해 조정**

---

## 0. 공통 원칙

1. **실거래가가 종합 점수다** (M3). 입지 가중치 합산 점수는 만들지 않는다. 입지 지표(H군)는 가격을 설명하는 데만 쓴다.
2. **실거래가·거래량·환금성을 교차 검증한다** (M4). 모든 가격 지표 옆에 거래 건수와 신뢰도를 표시한다.
3. **지역 평균과 단지값을 나란히** 보여준다 (M5).
4. **신호는 소수로**: 홈 화면에는 지표 전체가 아니라 기준선을 넘은 것만 올린다 (M8).

## 1. 실거래 전처리 (모든 가격 지표의 입력)

| 단계 | 규칙 | 근거 |
|---|---|---|
| 해제 거래 제외 | `해제여부 = O` 제외 | P5 |
| 직거래 제외 | `거래유형 = 직거래` 제외 (가족 간 거래는 시세보다 최대 30%·3억 낮게 가능) | 📖 p.401~404, p.135~136 |
| 면적 그룹 | 전용면적 소수점 버림 → 59/74/84/101… 그룹 | – |
| **층 보정** | 1~4층 = 저층. 저층 거래가를 `÷ 0.90`으로 중층 환산 (저층은 약 10% 낮음). 원값도 보존 | 📖 p.192, p.195, p.337, p.464 |
| 이상치 | 같은 단지·평형 직전 180일 중앙값 대비 ±30% 밖은 플래그 (삭제하지 않음) | 🔧 |
| 신고 지연 | 계약월 기준 61일이 지나지 않은 달은 "집계 중"으로 표시 | 설계 4.2 |
