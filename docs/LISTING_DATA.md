# 매물·호가 데이터 확보 방안 조사 (2026-10-10)

> 법률 자문이 아니다. 공개 보도·판례 평석·공식 안내를 정리한 것이며,
> 자동 수집을 실제로 하려면 해당 사이트 약관 원문과 전문가 확인이 필요하다.
> 이 클라우드 환경은 아래 사이트에 직접 접속할 수 없어 약관·robots.txt 원문은 확인하지 못했다.

## 1. 결론 (개정: 직접 입력 불가, 개인 전용)

매물·호가 원천 데이터를 합법적·자동으로 받을 곳은 없다. 그래서 **세 가지로 나눠** 대응한다.

| 경로 | 방법 | 자동화 | 법적 위험 | 채택 |
|---|---|---|---|---|
| **A. 실거래 파생 지표** | 이미 받는 실거래(매매·전월세)에서 호가 관점을 대신할 지표를 계산 | 완전 자동 | 없음 (공공데이터) | ✅ 기본 |
| **B. 공식 심리·수급 지표** | R-ONE 수급지수, 국토연구원 소비심리지수, 네이버 데이터랩 검색 트렌드 등 | 자동 (API·파일) | 없음 | ✅ 기본 |
| **C. 네이버 부동산 소량 개인 수집** | 관심 단지 N개만, 하루 1회, 저장만(공유·재배포 없음) | 자동 | **약관 위반**, 법적 판단 미정립, 차단 가능 | ⚠️ 사용자 결정 |
| D. 상용 API | 예: 오키씨(okyc.kr) 스타터 월 49만 원 (호가 포함 여부 미확인) | 자동 | 없음 | ❌ 비용 대비 불확실 |

### A. 실거래 파생 지표 (호가 대체)

| 지표 | 계산 | 대신하는 관점 |
|---|---|---|
| **급매 체결 비중** | 최근 4주 거래 중, 같은 단지·평형 직전 90일 중앙값보다 5% 이상 낮은 거래의 비율 | P4 반등 신호: 급매가 소진되면 이 비중이 떨어지고 가격 하단이 올라간다 |
| **가격 하단 추이** | 단지·지역별 실거래 하위 25% 가격의 이동 | P4, P5 호가 방향 (하단이 오르면 싼 매물이 사라진 것) |
| **직전 대비 상승 거래 비중** | 같은 단지·평형 직전 거래보다 비싸게 체결된 비율 | P5 호가 방향, C4 과열 속도 |
| **전세 신규 계약 수·갱신 비중** | 전월세 실거래의 계약구분(신규/갱신)·갱신요구권 사용 여부 (필드명은 기술문서로 확인 필요) | J5, C5 전세 매물 부족 (신규 전세 계약 감소 = 시장에 나온 전세가 적음) |
| **해제 거래 비율** | 해제 신고된 거래 / 전체 거래 | 보조 지표 (해석은 신중히) |

### B. 공식 심리·수급 지표

| 소스 | 지표 | 접근 | 비고 |
|---|---|---|---|
| 한국부동산원 R-ONE | 매매수급지수, 전세수급지수 (주간) | 오픈API (인증키) | 중개업소 설문 기반 |
| 국토연구원 | 부동산시장 소비심리지수 (월간, 0~200) | 공표 자료·KOSIS 여부 확인 필요 | 95 미만 하강 / 95~115 보합 / 115 이상 상승 국면 |
| 네이버 데이터랩 | 검색어 트렌드 ("급매", "아파트 매매", "전세" 등) | 공식 API (NAVER API HUB, 2026-07 이후 신규 키) | 상대 지수(기간 최댓값=100). 매수 관심도 대리 지표 |
| KB 데이터허브 | 매수우위지수, 매매거래활발지수 | 공식 API 미확인 | 오픈소스 PublicDataReader가 KB 데이터 조회를 지원하나 공식 허용 여부 미확인 → 보류 |
| 경매 | 진행건수·낙찰가율 | 공공 API 못 찾음 (지지옥션 월간 보도) | 보류 |

### C. 네이버 소량 개인 수집 — 선택 시 조건

- 개인 전용이라 다윈중개 사건(경쟁 서비스에 재게시)과 사정이 다르고, 저작권법 제30조(사적 이용 복제, 제94조로 DB에 준용)가
  적용될 여지가 있다. 그래도 **약관 위반은 분명**하고, 크롤링에 대한 법원 기준은 정립되지 않았다.
- 선택한다면: 관심 단지 20개 이하, 하루 1회, 사람이 보는 수준의 속도, 결과는 로컬에만 저장, 외부 공유·게시 금지.
- 네이버가 차단하거나 구조를 바꾸면 언제든 멈출 수 있는 **보조 경로**로만 설계한다 (A·B만으로도 체크리스트가 동작해야 함).

## 2. 근거

### 네이버 부동산 자동 수집의 위험

- 네이버파이낸셜 서비스 이용약관 제10조가 동의 없는 API 접근, 크롤링 등 자동 수단에 의한 정보 수집을 금지한다.
- **다윈중개 사건**: 네이버 부동산 매물을 크롤링해 게시한 다윈중개에 대해
  - 1심(서울중앙지법, 2024-10)이 **데이터베이스제작자 권리 침해**를 인정해 7천만 원 배상 판결
  - 항소심(2026-01 보도)도 네이버 측이 이겨 8천만 원 배상, 복제·전송 금지와 삭제 명령.
    "대규모·자동화된 반복 수집과 전송"이 DB의 상당 부분 복제에 해당할 수 있다고 봄
  - 저장하지 않고 아웃링크만 제공했다는 항변은 받아들여지지 않음
- **저작권법 제93조**: DB의 일부만 가져가더라도 반복적·체계적으로 가져가 제작자 이익을 해치면
  "상당한 부분의 복제"로 본다. 크롤링이 바로 이 조항에 걸린다.
- **저작권법 제94조**는 사적 이용 복제(제30조) 등을 DB에도 준용한다. 개인 비영리 소량 이용은
  이 예외에 해당할 여지가 있지만, 크롤링에 대한 허용 기준은 판례상 정립되지 않았다.
- 야놀자 vs 여기어때: 형사는 대법원 무죄(2022. 5. 12. 선고 2021도1533, 공개 정보 수집), 민사 1심은 부당경쟁행위로 10억 원 배상 보도.
  형사 무죄여도 민사 책임은 별개라는 사례다.

**판단**: 이 프로젝트는 개인용이라 경쟁 서비스였던 다윈중개와 사정이 다르다. 그래도 약관 위반이 분명하고
매일 반복 수집은 제93조의 "반복적·체계적" 요건에 가까워진다. 자동 수집기는 만들지 않는다.

### 공식 대체 지표

- **R-ONE 오픈API**: 한국부동산원 부동산통계정보시스템에서 인증키를 발급받아 REST로 호출한다.
  통계표 ID는 통계표 화면이나 Open API 목록에서 확인한다. 공공데이터포털에도 매매수급동향 파일데이터가 있다.
  공공데이터포털의 한국부동산원 API 일부는 폐기·통합 공지가 있었으니 R-ONE 쪽 명세를 기준으로 한다.
- **KB 데이터허브**: 매수우위지수 = 100 + "매수자 많음" 비중 − "매도자 많음" 비중.
  매매거래활발지수 = 100 + "활발함" 비중 − "한산함" 비중 (KB 데이터허브 이용가이드 2023-07).

## 3. 관점별 커버리지

| 관점 | A·B로 커버 | C까지 쓰면 |
|---|---|---|
| P2 호가 3%/5% 점검 | ❌ 호가 자체가 없음 | ✅ 관심 단지 호가 vs 기준 시세 |
| P4 급매 소진 + 호가 상승 = 반등 | ✅ 급매 체결 비중 하락 + 가격 하단 상승 + 매매수급지수 상승 | 매물별 호가 분포로 보강 |
| P5 매물 수보다 호가 방향 | △ 가격 하단·직전 대비 상승 비중 | ✅ 호가 중앙값 추이 |
| C5 매매·전세 매물 동시 증가 = 하락 초입 | △ 매매수급지수↓ + 전세수급지수↓ + 급매 체결 비중↑ | ✅ 관심 단지 매물 수 |
| J5 전월세 부족 → 매매 전환 | ✅ 전세수급지수↑ + 신규 전세 계약↓ + 전월세 실거래가↑ | – |
