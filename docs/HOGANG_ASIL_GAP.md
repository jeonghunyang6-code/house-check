## 3. 추천 (★ 먼저)

1. ★ 상세 탭 **매매·전세 장기 그래프 + 전세가율 선** (호갱노노 '매매/전세' 탭) — 전세 카드(⑥)를 이걸로
2. ★ **최고가 대비 하락 거래** 목록 (아실 '최근 하락', 호갱노노 '하락거래') — 관심 지역·평형만, 직거래 제외
3. ★ **관심 단지 시세선 겹치기** (아실 '여러단지비교') — 관심 탭 비교에
4. ★ 실거래 목록 **등기 표시** — 작은 수정
5. ☆ 시장 탭 **매매수급지수 추이** (아실 '매수심리'에 해당, 이미 수집 중)
6. ☆ 단지 **평당가 비교**(단지·동·구·서울), **3개월 내 나올 전세**
7. ☆ **관리비·보유세** — 실거주 월 비용. 새 수집기 필요(K-apt 관리비, 공시가격 자료 확인 전)
