# 송희구 관점 수집: 출처 정책과 진행 현황

## 1. 출처 등급

인사이트 규칙(`insight/rules/*.yaml`)에는 **A·B 등급 출처만** 근거로 쓴다.
규칙마다 `source` 필드에 영상 URL과 타임스탬프(또는 책 쪽수)를 남긴다.

| 등급 | 정의 | 예 | 규칙 근거 |
|---|---|---|---|---|
| **A** | 본인 채널, 본인 저서 | 유튜브 `작가 송희구`(@thewriter-song), 『나의 첫 번째 부동산 교과서』 | ✅ |
| **B** | 본인이 직접 출연해 말한 영상 원본 | 지식인사이드, 돈터뷰, KB부동산TV 출연분 | ✅ (영상 원본 확인 후) |
| C | 언론 기사의 직접 인용 | 뉴시스, 파이낸셜뉴스, 국민일보 | ⚠️ 후보로만 둠. A·B로 재확인 |
| D | 제3자 요약·후기·SNS 정리 | 블로그, 스레드, 커뮤니티 | ❌ 사용 안 함 |

## 2. 수집 파이프라인

```
① tools/insight_crawler/crawl.py
   채널 영상 목록 + 한국어 자막(수동 우선, 없으면 자동) 수집
   → data/raw/transcripts/<video_id>.json   (문장 단위 + 시작 초)
② 관점 추출 (Claude가 자막을 읽고 정리)
   → docs/insights/viewpoints.md           (관점 카드: 주장 / 근거 문장 / 출처 URL&t=초)
③ 규칙화
   → insight/rules/*.yaml                   (데이터로 판정 가능한 관점만)
```

- 원문 자막은 개인 분석용으로 로컬(`data/raw/`, git 제외)에만 보관하고,
  저장소에는 요약된 관점 카드와 출처 링크만 남긴다.
- 자동 자막은 오인식이 있으므로, 규칙에 쓰는 핵심 문장은 영상 해당 시점을 직접 확인한다.

### 진행 현황 (2026-10-10)

- 네트워크 허용 후 수집 완료: 채널 일반 영상·라이브 672개 메타데이터, 한국어 자막 626개 (나머지 46개는 자막 없음)
- 봇 확인으로 실패한 영상은 `crawl.py`를 다시 실행하면 빠진 것만 받는다 (2차 실행에서 모두 회수)
- 저서 『나의 첫 번째 부동산 교과서』(2026-06) 전권을 읽고 유튜브 관점과 통합 (원문은 로컬 `data/raw/book/`, git 제외)
- 최종 결과: [insights/viewpoints.md](insights/viewpoints.md), 지표 명세 [insights/indicators.md](insights/indicators.md)

## 3. 사전 조사 결과 (C등급) — 본인 채널 대조 결과

웹 검색으로 찾은 언론 보도의 직접 인용이다. 채널 자막과 대조한 결과를 `A 확인` 열에 적었다.
확인된 항목만 관점 카드 ID로 연결해 규칙 근거로 쓴다.

| # | 관점 | 데이터로 판정 가능? | 출처(C) | A 확인 |
|---|---|---|---|---|
| 1 | 집값 상승의 가장 큰 요인은 **유동성**과 물가(소득) 상승 | ✅ M2·CPI 추세 | 파이낸셜뉴스 2026-07-26 (네이트 뉴스 전재) | R1 |
| 2 | 규제가 강할수록 수요자가 조급해지고, 토지거래허가구역은 **양극화**를 키운다 | △ 상급지·하급지 변동률 격차 | 같은 기사 | G1·G2 |
| 3 | 다주택 규제·양도세 중과로 매물이 잠기면 **거래는 얼어도 가격은 안 빠진다** | ✅ 거래량↓ + 가격 보합/상승 | 같은 기사 | V2 |
| 4 | **전월세 상승이 매매가를 끌어올리는** 구조, 15억 이하 구간이 가파르게 상승 | ✅ 전세 변동률, 가격대별 상승률 | 뉴시스 2026-06-08 | J5, L5 |
| 5 | 금리가 올라도 2021년처럼 3~4배 수준이 아니면 방향이 바뀌기 어렵다 | ✅ 기준금리·주담대 금리 변화폭 | 같은 기사 | 미확인 (채널에서 '3~4배' 발언 못 찾음) |
| 6 | 쇼핑몰·병원·대형마트는 호재가 아니고, **중심지 직결 지하철**이 진짜 호재 | ✅ 입지 레이어 가중치 | 파이낸셜뉴스 2026-07-26 | 일부 D3 (쇼핑몰은 원래 호재 아님) |
| 7 | 호가가 아니라 **최근 실거래가 대비** 과하지 않은 가격이면 검토 가능 | ✅ 전고점 대비율 | KB Think 2026-02 | P1·P2 |
| 8 | 갈아타기는 확실한 상급지로, **가격 1.5배 이상**이어야 의미가 있다 | ✅ 단지 간 가격 비율 | 지식인사이드 출연분 보도 (네이트 뉴스) | L4 |
| 9 | 같은 단지 평수 늘리기는 위험 — 거래마다 세금·수수료로 약 1억 원 | △ 거래비용 계산기 | 같은 보도 | 미확인 |
| 10 | 입지 차이가 크면 입지, 비슷하면 신축 | △ 입지 점수 + 연식 | 돈터뷰 출연분 요약 | 미확인 |
| 11 | 외곽에서 거래량이 적거나, 거래가 많아도 가격이 안 오르는 곳은 정리 | ✅ 거래량·가격 동시 판정 | 강연 후기 (D등급, 참고만) | V4 |
