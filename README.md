# house-check

송희구 작가의 시세 해석 관점을 데이터로 자동화한 수도권 아파트 시장 분석기.

- 오늘의 실거래 · 신고가 판정
- 신고 지연을 보정한 거래량 분석
- 주간 가격 동향 지도 · 연속 상승 주수
- 금리 · 유동성 · 공급 · 인구 시장지표
- 입지 분석 지도
- 규칙 기반 시장 국면 해석
